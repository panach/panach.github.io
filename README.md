# panach portfolio

포트폴리오: https://panach.github.io

빌드 도구나 외부 의존성이 없는 HTML/CSS 페이지입니다.

## 수정과 배포

- `index.html`에서 소개 문구와 프로젝트 카드를 수정합니다.
- 새 프로젝트는 `article.project`를 복사하고 설명 및 저장소 링크를 변경합니다.
- `main` 브랜치 루트(`/`)를 GitHub Pages 배포 소스로 사용합니다.
- `main`에 push하면 GitHub Pages가 자동으로 다시 배포합니다.

## 로컬 확인

```sh
python3 -m http.server 8000
```

http://localhost:8000 에서 확인합니다.
